# Jeky Project

Ini struktur Android Kotlin + Jetpack Compose yang sudah dirapikan.

## Lokasi file penting

- Kotlin: `app/src/main/java/id/aejeky/presentation/MainActivity.kt`
- Logo: `app/src/main/res/drawable/logo_jeky.png`
- Manifest: `app/src/main/AndroidManifest.xml`
- Gradle app: `app/build.gradle.kts`

## Cara run paling gampang

1. Buka Android Studio.
2. Pilih **Open**.
3. Pilih folder `jeky-project-correct`.
4. Tunggu Gradle Sync selesai.
5. Pilih emulator atau HP Android.
6. Klik tombol **Run**.

Kalau mau lanjut coding di VS Code, buka folder root `jeky-project-correct`, bukan folder `app` saja.
